# 🏎️ Neon Rush

A mobile-friendly browser racing game built with HTML5 Canvas.

## Controls
- Mobile: hold ◀ / ▶
- Keyboard: A/D or Arrow keys
- Nitro: NITRO button or Space
- Enter: start/restart

## Run
Open `index.html` in a browser.

GitHub Pages deployment is configured in `.github/workflows/pages.yml`.
